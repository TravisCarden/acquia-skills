# acli Skills

Command-line skills for [Acquia CLI (acli)](https://github.com/acquia/cli).

## Skills

| Skill | Description |
|-------|-------------|
| [getting-started](getting-started/SKILL.md) | Install acli, authenticate, ACSF login, telemetry, cache management |
| [ide-management](ide-management/SKILL.md) | Create, open, share, and manage Cloud IDEs |
| [application-management](application-management/SKILL.md) | List/open apps, create projects, deploy, archive export, app:vcs:info |
| [ssh-key-management](ssh-key-management/SKILL.md) | Create, upload, list, inspect, and delete SSH keys |
| [environment-management](environment-management/SKILL.md) | Create/delete CDEs, mirror environments, crons, SSL certificates |
| [pull-push](pull-push/SKILL.md) | Pull/push code, database, files, and build artifacts |
| [remote-access](remote-access/SKILL.md) | SSH into environments, run remote Drush, download aliases, tail logs |
| [codestudio](codestudio/SKILL.md) | Set up Code Studio, change PHP version |
| [scripting](scripting/SKILL.md) | Use acli non-interactively in scripts and CI/CD pipelines |
| [troubleshooting](troubleshooting/SKILL.md) | Diagnose and fix common acli errors |
